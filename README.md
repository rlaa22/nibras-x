# NIBRAS X — Building 12

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In the terminal run `npm install`.
4. Then run `npm run dev`.
5. Open http://localhost:3000

## Deploy
Push the project folder contents to a GitHub repository and import that repository into Vercel. The app uses the standard Next.js preset.

The current version is a responsive welcome-page prototype with the supplied Building 12 photo. The button is an interface interaction only; live camera AR is not implemented yet.
